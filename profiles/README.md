# Profiles

Versioned calibration and kit data. Nothing here is typed from memory: every
file is produced by a script from real photos, and records the phone, date and
file hashes it came from.

- `mat_reference_<version>_<copy>.json` — registered reference values for one
  printed copy of the reference colour card (written by `scripts/register-mat.ts`,
  Step 4).
- Kit profiles (Session 2).
